因为太烦键盘的**Shift+“”**才能打出**双引号**说话了，所以我用小鲸娘（DeepSeek 4.1f）写了个插件

在聊天输入栏的**发送键左边**加一个 **“”** 按钮。

点一下，输入框里就出现一对中文双引号，光标停在中间，直接打字就行：

> 点按钮 → 输入框变成 `“_”`（`_` 是光标位置）→ 打字 → `“你好”`

## 怎么用

按钮就在发送键左边：

```
…… 输入框 …  [“”] [发送]
```

点它有三种情况，都是你期望的结果：

| 你现在的情况 | 点完的结果 |
| --- | --- |
| 选中了一段文字 | 给这段文字套上符号：`说话` → `“说话”` |
| 光标正好在一对空符号中间 | 跳到右半边右边：`“_”` → `“”_`（不会再套一层，`_` 是光标） |
| 其他情况（包括空输入框） | 插入一个空符号，光标停中间：`“_”` |

几个小细节：

- **光标不会跑**：点按钮不会把光标从输入框里抢走，符号就插在你刚才停的地方，不会跑到整段文字最后面。
- **可以撤销**：点错了按 `Ctrl + Z` 就回来。
- **能删不能反**：如果选中的文字本来就带着符号，再点一次会变成 `““说话””`。
  这是故意的——免得你双击选个词、顺手点一下，符号反而被拿走了。想删直接删就好。

## 换成别的符号

菜单里默认放的是常见引号，但**放什么符号都行**：`「」`、`（）`、`《》`、`【】`，或者
`……`、`——`、`※`、`、` 都可以。

把鼠标**停在按钮上**（手机上点一下按钮），按钮上方会弹出一排，点哪个就插入哪个：

```
      ┌────────────────────────────────┐
      │ “”  「」  （）  《》  【】  ""  '' │   ← 鼠标移上去选
      └────────────────────────────────┘
                 [“”]  [发送]
```

- 点中的那个会成为**按钮的默认符号**，以后直接点按钮就插它，按钮上的字也跟着换。
- 正在用的那个会高亮；点下去时那一项会轻轻跳一下，让你知道点到了。
- 菜单是**从按钮那儿弹出来**的（缩放 + 淡入），收起时会缩回去，不是硬生生地出现／消失。
  不想要这个动画可以在设置里关掉。
- 鼠标移开就自动收起，不用点别处关。
- 想要哪些引号可以自己配，见下面的「自己增删菜单里的引号」（默认就是上面这一排）。

> 窗口窄的时候，这排引号**始终保持一行**，放不下就左右滑动（不会折成两行，
> 所以菜单的高度和位置是稳定的）。如果上方空间不够，菜单会自己变小并在内部滚动，
> **不会盖住引号按钮和发送键**；调整窗口大小或输入框长高时，菜单也会跟着重新贴到按钮上方。

### 手机上怎么用

手机和平板**没有「鼠标悬停」这个动作**，所以扩展会自动改一套操作方式：

| | 电脑（有鼠标） | 手机 / 平板（触屏） |
| --- | --- | --- |
| 点一下按钮 | 直接插入当前引号 | **弹出引号菜单** |
| 再点一下按钮 | — | **插入当前引号**并收起菜单 |
| 想换一个引号 | 鼠标移到菜单上点 | 点菜单里的那个引号 |
| 不想选了 | 鼠标移开 | 点菜单以外的任何地方 |

也就是手机上「点两下 = 用默认引号」，和电脑上点一下的结果一样，只是多看一眼菜单；
想换引号就在第一下之后直接点菜单里那个。

这个判断是自动的（看设备是不是触屏），**也可以手动固定**，见下面的「快捷菜单」设置。

## 调整大小

按钮上的“”两个字**可以调大调小**：

1. 点顶部的**扩展**图标，打开扩展面板
2. 找到 **快捷符号按钮**，点开
3. 拖动 **按钮大小** 滑块 —— 输入栏里的按钮会**立刻跟着变**，不用重启 

**恢复默认**点滑块右边的 ↺ 就行。

> 滑块调的是“”两个字的大小，按钮的方框还是跟旁边图标一样大，所以怎么拖都不会把输入栏撑变形。

## 设置项一览

| 设置项 | 说明 |
| --- | --- |
| 按钮大小 | 50% – 150%，默认 82%。拖动即时生效 |
| 显示“”按钮 | 不想看到这个按钮就取消勾选 |
| 引号 | 按钮当前插入的引号，默认中文引号 `“”`。从弹出菜单里点过的引号也会记到这里 |
| 快捷菜单 | 决定按钮怎么打开引号菜单：**自动**（触屏点按打开、鼠标悬停打开，默认）/ **总是用点按打开** / **只用鼠标悬停，点按直接插入** |
| 菜单弹出动画 | 菜单弹出／收起时的缩放淡入动画。默认开；嫌花哨或觉得费性能就取消勾选，变成瞬间出现／消失 |
| 菜单里的引号 | 一排可编辑的输入框，用来增删改弹出菜单里提供的引号。见下一节 |
| 快捷键 | 想用键盘触发就填，例如 `Ctrl+Alt+Q`。**留空 = 不用快捷键**，不占任何键 |
| 选中文字时给它加引号 | 取消勾选后，有选中文字时也只插入一对空引号，不包裹 |

改完会**自动保存**，下次打开还是这样。

> 「快捷菜单」的三个选项都是给用户兜底的：自动模式认错设备了（比如带触摸屏的笔记本、
> 或者想用鼠标操作的平板），就在这里手动改成你习惯的那种。

## 自己增删菜单里的符号

在插件设置面板里往下拉，找到 **「菜单里的符号」**，那里就是一排可以改的输入框：

```
菜单里的符号
鼠标停在按钮上（手机上点一下按钮）会弹出这一排。放引号、括号、省略号、破折号都行。
●  “”        [✓]  [🗑]     ← ● 表示按钮当前用的就是这个
○  「」      [✓]  [🗑]
○  （）      [✓]  [🗑]
  ...
[ 加上一个符号，例如 …… ]  [+ 添加]  [↺]
```

- **改**：直接改输入框里的符号，回车或点别处生效。
- **✓**：把这个符号设为按钮当前使用的（也就是按钮上显示的那个）。
- **🗑**：从菜单里删掉这一项。
- **添加**：输入符号后按回车或点「添加」，会加到列表末尾。
- **↺**：恢复成默认的那几个。

规则：**一个字符也行**（例如 `…`）；空的、重复的会被拒绝（输入框退回原值）；
删光了会自动恢复成默认那几个，不会让菜单变空。逗号 `,` 也可以当符号用。

### 插入规则（长度决定）

| 符号长度 | 插入行为 | 例子 |
| --- | --- | --- |
| 两个字符以上 | 插一份，**光标停在中间** —— 和引号一样，直接打字就成对 | `“”` → `“_”`；`……` → `…_…` |
| 一个字符 | 插一份，光标跟在后面 | `…` → `…_` |

选中文字时的行为不变：两个字符以上的符号会把选中内容包起来（`说话` → `“说话”`），
单字符符号则直接替换选中内容。

## 直接改配置文件（可选）

上面那些设置都会写进 `<数据根目录>\default-user\settings.json` 的
`extension_settings.tauritavernQuickQuote`，也可以直接改这个键（改完重开界面）：

```json
"tauritavernQuickQuote": {
    "quote": "“”",
    "quoteOptions": ["“”", "「」", "（）", "《》", "【】", "\"\"", "''", "……"],
    "menuMode": "auto",
    "animations": true
}
```

- `quoteOptions` 是**数组**（面板写的就是这个形式）。旧版本留下的**逗号分隔字符串**仍能读入，
  但那种写法里逗号就不能当符号用了，建议用数组。
- 每个选项至少一个字符。
- 列表为空时会回退成默认那几个。
- `quote`（当前用的符号）一定会出现在菜单里，即使你没写进 `quoteOptions`。
- `menuMode` 取 `auto` / `always` / `never`，含义同设置面板里的「快捷菜单」。
- `animations` 设 `false` 等于取消勾选「菜单弹出动画」。
