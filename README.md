因为太烦键盘的**Shift+“”**才能打出**双引号**说话了，所以我用小鲸娘（DeepSeek 4.1f）写了个插件

在聊天输入栏的**发送键左边**加一个 **“”** 按钮。

点一下，输入框里就出现一对中文双引号，光标停在中间，直接打字就行：

> 点按钮 → 输入框变成 `“_”`（`_` 是光标位置）→ 打字 → `“你好”`

## 怎么用

按钮就在发送键左边：

```
…… 输入框 …  [“”] [发送]
```

点它有三种情况，都是你期望的结果：

| 你现在的情况 | 点完的结果 |
| --- | --- |
| 选中了一段文字 | 给这段文字套上引号：`说话` → `“说话”` |
| 光标正好在一对空引号中间 | 跳到右引号右边：`“_”` → `“”_`（不会再套一层，`_` 是光标） |
| 其他情况（包括空输入框） | 插入一对空引号，光标停中间：`“_”` |

几个小细节：

- **光标不会跑**：点按钮不会把光标从输入框里抢走，引号就插在你刚才停的地方，不会跑到整段文字最后面。
- **可以撤销**：点错了按 `Ctrl + Z` 就回来。
- **能删不能反**：如果选中的文字本来就有引号，再点一次会变成 `““说话””`。
  这是故意的——免得你双击选个词、顺手点一下，引号反而被拿走了。想删引号直接删就好。

## 想用别的符号比如说（）或者「」这些？把鼠标放上去试试（新更新）

把鼠标**停在按钮上**，按钮上方会弹出一排引号，点哪个就插入哪个

```
      ┌────────────────────────────────┐
      │ “”  「」  （）  《》  【】  ""  '' │   ← 鼠标移上去选
      └────────────────────────────────┘
                 [“”]  [发送]
```

- 点中的那个会成为**按钮的默认引号**，以后直接点按钮就插它，按钮上的字也跟着换。
- 正在用的那个会高亮。
- 鼠标移开就自动收起，不用点别处关。
- 想要哪些引号可以自己配，见下面的 `quoteOptions`（默认就是上面这一排）。

### 手机上怎么用

手机和平板**没有「鼠标悬停」这个动作**，所以扩展会自动改一套操作方式：

| | 电脑（有鼠标） | 手机 / 平板（触屏） |
| --- | --- | --- |
| 点一下按钮 | 直接插入当前引号 | **弹出引号菜单** |
| 再点一下按钮 | — | **插入当前引号**并收起菜单 |
| 想换一个引号 | 鼠标移到菜单上点 | 点菜单里的那个引号 |
| 不想选了 | 鼠标移开 | 点菜单以外的任何地方 |

也就是手机上「点两下 = 用默认引号」，和电脑上点一下的结果一样，只是多看一眼菜单；
想换引号就在第一下之后直接点菜单里那个。

这个判断是自动的（看设备是不是触屏），**也可以手动固定**，见下面的「快捷菜单」设置。

## 调整大小

按钮上的“”两个字**可以调大调小**：

1. 点顶部的**扩展**图标，打开扩展面板
2. 找到 **快捷输入引号 Quick Quote**，点开
3. 拖动 **按钮大小** 滑块 —— 输入栏里的按钮会**立刻跟着变**，不用重启 

**恢复默认**点滑块右边的 ↺ 就行。

> 滑块调的是“”两个字的大小，按钮的方框还是跟旁边图标一样大，所以怎么拖都不会把输入栏撑变形。

## 设置项一览

| 设置项 | 说明 |
| --- | --- |
| 按钮大小 | 50% – 150%，默认 82%。拖动即时生效 |
| 显示“”按钮 | 不想看到这个按钮就取消勾选 |
| 引号 | 按钮当前插入的引号，默认中文引号 `“”`。从弹出菜单里点过的引号也会记到这里 |
| 快捷菜单 | 决定按钮怎么打开引号菜单：**自动**（触屏点按打开、鼠标悬停打开，默认）/ **总是用点按打开** / **只用鼠标悬停，点按直接插入** |
| 快捷键 | 想用键盘触发就填，例如 `Ctrl+Alt+Q`。**留空 = 不用快捷键**，不占任何键 |
| 选中文字时给它加引号 | 取消勾选后，有选中文字时也只插入一对空引号，不包裹 |

改完会**自动保存**，下次打开还是这样。

> 「快捷菜单」的三个选项都是给用户兜底的：自动模式认错设备了（比如带触摸屏的笔记本、
> 或者想用鼠标操作的平板），就在这里手动改成你习惯的那种。

## 自定义弹出菜单里的引号（新更新的）

设置面板里没有做这一项，需要手写进配置文件。打开
`<数据根目录>\default-user\settings.json`，找到 `extension_settings` 里的
`tauritavernQuickQuote`，加上 `quoteOptions`（**逗号分隔**），然后重开界面：

```json
"tauritavernQuickQuote": {
    "quote": "“”",
    "quoteOptions": "“”,「」,（）,《》,【】,\"\",''",
    "menuMode": "auto"
}
```

- 每个选项至少两个字符，带逗号的会被忽略。
- 列表里不足两项时会回退成默认那一排。
- `quote`（当前用的引号）一定会出现在菜单里，即使你没写进 `quoteOptions`。
- `menuMode` 取 `auto` / `always` / `never`，含义同设置面板里的「快捷菜单」。
